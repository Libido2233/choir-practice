# 声部练习室

将合唱、阿卡贝拉或带伴奏的合唱谱整理为离线练习 HTML。使用 `assets/player.html` 的现有界面，沿用用户的声部与唱名选择。

## 按改动选择流程

- **已有练习页更新界面**：读取项目的已校正 JSON，用 `scripts/build_player.py` 重新生成；复用音符、歌词和谱图。
- **修改音符或歌词**：更新结构化源数据和受影响的谱面，再生成；保留可编辑乐谱及校正记录。
- **处理新谱**：按 [识谱与校对](references/score-workflow.md) 准备 MusicXML/MXL 或识谱初稿，逐部校对后生成 JSON、谱图与简谱。生成器只接收整理后的 JSON。

数据格式、生成和检查命令见 [播放器数据](references/player-data.md)。优先复用本地依赖；识谱结果与分阶段数据保存在项目中，供继续校正。

## 默认页面

- “我练”、听音多选和各声部音量独立；音量可点击增减或直接输入。
- 当前行最多一个参照在上、练习声部在下；参照默认优先 Solo，无 Solo 时只显示自己。下一行固定跟随练习声部，选择与音量随曲目保存。
- 五线谱下方提供完整简谱与音符关联的文字歌词。默认固定唱名 `1=C，中音1=C4`；音高以实际发声为准。原谱未填词处留空。
- 播放/暂停固定在底部。慢练、分段循环、预备拍、节拍器及按小节分组的逐音试听直接显示；试听使用带播放图标的按钮。
- 单文件内嵌谱图、数据和音色，适应页面宽度。代码、模板与 Skill 采用 MIT；钢琴采样保持 CC BY 3.0，素材许可保留在文件与 HTML 源码中。

## 验证与交付

默认用静音检查器与模拟音频验证功能；真实试听按用户要求进行，结束即停止。运行 `scripts/check_project.py` 核对项目数据和成品；修改播放器逻辑时再运行生成器自检及 `scripts/check_player.cjs`。

对照原谱检查音高、节奏、歌词、分部和跨行延音；程序通过不代替识谱校对。未校对声部用 `--draft`。成品命名为 `声部练习室 - 曲名.html`，避免将练习声部写进文件名。交付 HTML 与简短打开方法，说明影响练习的待校对内容；区分模拟测试、浏览器和手机实测。

分享 Skill 时只打包本文件夹，保留音色许可，排除个人曲谱、数据、路径及临时文件。
