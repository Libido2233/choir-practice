# 声部练习室

将个人旋律谱或多声部乐谱整理为离线练习 HTML，支持独唱、合唱、阿卡贝拉及带伴奏的练唱。一律用 `scripts/build_player.py` 套 `assets/player.html`（播放器 v2）生成，不手写或另做界面；沿用用户的声部与唱名选择。有原谱 PDF 时加 `--score-pdf` 嵌入原谱页。

## 按改动选择流程

- **已有练习页更新界面**：读取项目的已校正 JSON，用 `scripts/build_player.py` 重新生成；复用音符、歌词和谱图。
- **修改音符或歌词**：更新结构化源数据和受影响的谱面，再生成；保留可编辑乐谱及校正记录。
- **处理新谱**：按 [识谱与校对](references/score-workflow.md) 准备 MusicXML/MXL 或识谱初稿，逐部校对后生成 JSON、谱图与简谱。生成器只接收整理后的 JSON。

数据格式、生成和检查命令见 [播放器数据](references/player-data.md)。优先复用本地依赖；识谱结果与分阶段数据保存在项目中，供继续校正。

## 选择练习对象

沿用用户指定的声部或旋律；单旋律直接使用该轨。多声部未指定目标时，按谱面顺序默认选择第一个演唱声部并允许切换，不预设男高音、SATB 编制或必有 Solo。保留原谱声部名称；唱名体系沿用用户选择。

## 默认页面

页面功能以本节列出的练习控件为限；原谱、校正记录和编辑资料保存在项目文件中。优先沿用原谱分行或完整乐句；按每行音符和歌词的实际宽度安排间距，谱面、简谱与歌词共用横坐标及缩放比例，随容器宽度整体等比例缩放。核对密集音符、长歌词及窄屏排版，保持文字与记谱符号清晰分离。

- 切换“我练”时重设听音组合：目标声部100%；练非主唱时主唱50%，其余声部30%，只勾选目标与主唱；练主唱时只勾选目标。之后仍可独立勾选和调音量。参照谱选择不改变听音组合。
- 当前行最多一个参照在上、练习声部在下；参照默认优先 Solo，无 Solo 时只显示自己。下一行固定跟随练习声部，选择与音量随曲目保存。
- 对照原谱标注旋律交接，用 `melodyGuide` 按拍切换参照谱和默认听音（自己100%、参照50%）。交织或无明确旋律处留空，手动调节优先；完整主唱谱沿用原设置。
- 五线谱下方提供完整简谱与音符关联的文字歌词。默认固定唱名 `1=C，中音1=C4`；音高以实际发声为准。原谱未填词处留空。
- 页面分两种用法，顶部用大号分段标签区分：「听着练」（有声音、跟着唱）和「只看谱」（不出声、自选声部）。切到只看谱时停止播放并隐藏播放条；地址加 `#read` 可直接打开看谱；所选用法与看谱设置随曲目保存。
- 只看谱：「分声部」按行纵向排列，用声部胶囊自选显示哪些声部（默认我练＋参照），可开关简谱；「原谱」逐页显示原谱 PDF 的图片，双指放大。没有 `scorePages` 时只显示分声部。
- 音频：用纯 JS 把当前混音（含预备拍、节拍器）合成为一段 WAV，交给一个隐藏的 `<audio>` 播放，不用实时 Web Audio 调度。这样静音键下有声、锁屏/后台继续、系统锁屏控件可用（Media Session：上一首/下一首＝上一节/下一节）。改音量、声部、速度、循环等设置后在后台重新合成，从当前位置无缝接上。逐音试听同样同步合成后播放。各曲的变速、摇摆通过页面里的 `performanceAt`/`writtenAt` 函数接入，断奏、打击照常处理。
- 只有一个播放位置：点小节、拖动条（吸附到小节开头）、上一节/下一节、上一行/下一行都只移动它；播放中直接跳过去继续，不重复预备拍；暂停时只移动位置。每次改播放位置都先静音、确认到位再开声，避免手机上开播时漏出旧位置的杂音。从暂停开始播放时，若开预备拍，则从该小节开头打预备拍后进入。
- 底部播放条只放：当前小节与状态、当前音、拖动条（循环范围以色带标出）、「⏮ 回第 N 小节」（循环时回循环起点，否则回第 1 小节）、「‹ 上一节」「▶ 播放」「下一节 ›」（循环时不越过循环两端；窄屏只显示箭头）。不做“锁屏听”等独立模式或第二套播放控件。
- 循环分两种：手动范围（开关“循环”+起止小节，只在开启时生效；跳出范围自动关闭循环）和「循环本行」开关。循环本行不改写手动范围，换行时跟着移到新的一行，再点一次结束，回到原来的状态。
- 整页 `touch-action:manipulation` 防双击缩放，保留双指缩放。手机静音、后台与文件预览的兼容性以设备实测为准。
- 界面风格：暖白纸面（背景 #f4f1ea、卡片 #fffdf8、细边 #e7e1d6）＋深青强调色（#0f6b5f）；只看谱用墨蓝（#2f4b6e），让两种用法一眼可分；橙色（#d2752b）只用于播放光标和循环色带。界面文字用系统无衬线字体（PingFang SC / 微软雅黑），曲名与歌词用宋体；谱号及升降号使用完整支持音乐符号的字体。
- 版式：卡片圆角 16–18px、轻阴影；分组为「我练＋听哪些声部」「速度与循环」「谱面」「逐个听音」。开关用胶囊开关样式，音量为「− 数值 % ＋」步进器，关闭的声部音量变淡；慢练/原速用分段按钮；行切换用「‹ n/总数 ›」。底部播放条为悬浮圆角毛玻璃条，播放键为大号胶囊主按钮。不放说明性小字（如“有声音 · 跟着唱”“双指可放大”这类提示），按钮至少 42px 高，360px 宽仍不换乱。

- 单文件内嵌谱图、数据和音色，适应页面宽度。代码、模板与 Skill 采用 MIT；钢琴采样保持 CC BY 3.0，素材许可保留在文件与 HTML 源码中。

## 验证与交付

默认用静音检查器与模拟音频验证功能；真实试听按用户要求进行，结束即停止。运行 `scripts/check_project.py`（生成时用了 `--score-pdf` 就同样加上）核对项目数据和成品；`node scripts/check_player.cjs [成品HTML]` 检查播放、定位、循环、热切换、melodyGuide 和只看谱（模拟、不发声）；修改模板后再跑 `build_player.py --self-test`。

对照原谱检查音高、节奏、歌词、分部和跨行延音；程序通过不代替识谱校对。未校对声部用 `--draft`。成品命名为 `声部练习室 - 曲名.html`，避免将练习声部写进文件名。交付 HTML 与简短打开方法，说明影响练习的待校对内容；区分模拟测试、浏览器和手机实测。

分享 Skill 时只打包本文件夹，保留音色许可，排除个人曲谱、数据、路径及临时文件。
